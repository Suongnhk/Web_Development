# Web_Development

## Overview
This project develops a specialized e-commerce website, FIT&FRESH.VN, designed for health-conscious consumers in Vietnam. The platform provides nutritious meals, healthy snacks, beverages, and fitness-related products, while integrating personalized meal planning and nutrition consultation. The goal is to combine modern web technologies with practical business strategies to deliver a complete health and wellness shopping experience.

## Objectives
- Build a responsive e-commerce platform optimized for mobile and desktop
- Implement essential online shopping features: registration, cart, order, and secure payment
- Provide personalized services including TDEE and BMI calculators, and diet consultation
- Establish an admin system for managing products, orders, customers, blogs, and promotions
- Promote sustainability by offering eco-friendly packaging and organic sourcing

## Tools & Technologies
- Frontend: Angular, TailwindCSS
- Backend: Node.js (Express.js)
- Database: MongoDB
- IDE & Version Control: Visual Studio Code, GitHub
- Design & Modeling: BPMN, Use Case diagrams, Mockups
